## Project Description
A wellness awareness website designed to provide a safe space for users. The application features informative resources and **AI-powered supportive messages** to help users navigate their mental health journey and promote emotional well-being.

## Tech Stack
* **Vue 3** (Composition API)
* **Vite** (Build Tool)
* **Vue Router** (Navigation)
* **OpenAI/Gemini API** (AI Support Messaging)

## Getting Started
1. Clone the repository
2. Install dependencies: `npm install`
3. Run the development server: `npm run dev`
